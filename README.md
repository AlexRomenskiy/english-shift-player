# English Lions Player

Плеер для shadowing к приложению English Lions: YouTube по фразам, петля, замедление, пауза на повтор, запись голоса и сверка произношения.

Открывается ссылкой из English Lions. Текст фраз передаётся в части ссылки после `#`, поэтому он не уходит на сервер и в репозитории ничего не хранится.

Работает в Chrome и Safari на компьютере и телефоне. На телефоне можно добавить на главный экран.
